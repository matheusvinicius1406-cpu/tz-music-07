# Blocked / Forbidden Paths

## Spotify protected audio

- Status: blocked.
- Reason: project rules forbid fetching protected Spotify audio, bypassing DRM, extracting app secrets, or reimplementing closed protocols to play restricted audio.
- Alternative: use Spotify Web API only for OAuth metadata import, then resolve tracks against legal sources, user servers, local library, or opt-in providers with clear warnings.

## Official commercial app reverse engineering

- Status: blocked.
- Reason: project rules forbid decompiling, instrumenting, hooking, or extracting keys/tokens/secrets from Spotify, Deezer, Apple Music, Tidal, Amazon Music, YouTube Music/YouTube, or SoundCloud official apps.
- Alternative: use public docs, app-store pages, screenshots, and normal product benchmarking only.
