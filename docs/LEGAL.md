# Legal Notes

Project license: GPL-3.0-only.

Allowed:

- Read public open-source code, documentation, issues, and PRs.
- Use official public APIs within their published terms.
- Import Spotify metadata through the official Spotify Web API with the user's OAuth consent.
- Support local files, radio, podcasts, Creative Commons/public-domain catalogs, user-owned servers, and independent catalogs with lawful streaming APIs.

Forbidden:

- Bypassing DRM or media encryption.
- Extracting secrets or tokens from official commercial apps.
- Fetching protected Spotify audio.
- Impersonating official clients to obtain restricted audio.
- Collecting telemetry without explicit opt-in.

Any feature that crosses these lines must be documented in `docs/research/BLOCKED.md` and replaced with a lawful alternative.
