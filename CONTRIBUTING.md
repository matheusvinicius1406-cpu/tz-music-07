# Contributing

Use small, reviewable changes with Conventional Commits.

Before implementing a provider or protocol, add or update the matching research note in `docs/research/` and cite public source evidence. Do not copy code blocks from reference projects.

If a task appears to require DRM bypass, private tokens, closed protocol impersonation, protected audio extraction, or license-incompatible code, stop and document it in `docs/research/BLOCKED.md`.
